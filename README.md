
## C Programming Labs

Throughout my C Programming module, I have completed practical labs focused on developing my understanding of procedural programming, memory management and problem-solving.

### Topics and Concepts Covered

- **Programming Fundamentals:** Variables, data types, operators, input/output and format specifiers.
- **Control Structures:** If/else statements, switch statements, for loops, while loops and do-while loops.
- **Arrays:** One-dimensional and multidimensional arrays, traversal, manipulation and processing.
- **Strings:** String manipulation, character handling, string reversal and palindrome checking.
- **Functions:** Function declarations, prototypes, parameters, return values and modular programming.
- **Pointers:** Pointer declaration, dereferencing, pointer arithmetic and passing pointers to functions.
- **Structures:** Creating and managing structures using `struct` to organise related data.
- **Dynamic Memory Allocation:** Using `malloc()`, `realloc()` and `free()` to allocate, resize and release memory.
- **Memory Management:** Understanding memory leaks, NULL pointers and safe memory allocation.
- **Algorithms:** Array sorting, searching, reversing and mathematical operations.
- **Multidimensional Arrays:** Matrix manipulation, row calculations and multidimensional array processing.

### Practical Skills Developed

- Developing modular programs using reusable functions.
- Processing and manipulating arrays using loops and pointers.
- Creating and managing dynamically allocated memory.
- Implementing sorting and searching algorithms.
- Working with strings and character manipulation.
- Debugging logical errors and memory allocation issues.
- Improving code structure, efficiency and problem-solving skills.
